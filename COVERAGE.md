# Coverage

Two systems: Rust (`cargo llvm-cov`) + Web (Vitest `v8`). Both feed `lcov.info`; `normalize-lcov.mjs` rewrites paths to repo-root-relative before `diff-cover`.

## Run

```bash
# Rust only
mise run coverage:rust    # cargo llvm-cov + html/text in target/llvm-cov/

# Web only  
# Requires `pnpm exec vitest run --coverage` (provider v8, dir coverage/)
# Browser tests (playwright) may skip; see vitest.config.ts exclusions.

# Both + normalize
mise run coverage           # runs rust + web

# Gate (fail-closed, ADR 38)
mise run coverage:gate     # normalize -> diff-cover against origin/main (fail-under=85)
```

Config sources (single truth):
- Rust exclusions: `coverage-ignore.txt` (read by `cargo llvm-cov --ignore-filename-regex` and `normalize-lcov.mjs`)
- Web exclusions: `coverage-ignore.txt` (parsed by `vitest.config.ts` into `webExcludes`)
- Reports dir: `coverage/` (gitignored; regenerated by `mise run coverage`)
- HTML index: `coverage/index.html`; parsed via `scripts/normalize-lcov.mjs`

## Parsing reports

```bash
# Extract per-crate line counts from rust.lcov
python3 -c "
import re
files = {}
for line in open('target/llvm-cov/rust.lcov'):
    if line.startswith('SF:'):
        f = line[3:].strip()
        files[f] = files.get(f,0)+1
for k,v in sorted(files.items(), key=lambda x:-x[1])[:10]:
    print(k, v)
"

# Check coverage-check gate result
cat target/llvm-cov/patch.md 2>/dev/null | head -20
```

## Key files

| File | Purpose |
|---|---|
| `mise.toml` | `tasks.coverage`, `tasks."coverage:rust"`, `tasks."coverage:gate"` |
| `vitest.config.ts` | `provider: 'v8'`, `reportsDirectory: 'coverage'`, `webExcludes` |
| `coverage-ignore.txt` | Exclusions (single source for Rust regex + web globs) |

| `Cargo.toml` / `package.json` | `cargo-llvm-cov` (mise), `@vitest/coverage-v8`, `playwright` |
