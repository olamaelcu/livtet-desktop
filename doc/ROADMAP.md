# Project Roadmap

The goals of this project are as follows:

- provide a local library experience
- allow for custom theming of the library interface
- fetch book info from multiple locations like
  - [ ] OpenLibrary
  - [ ] Google Books (authenticated via app-wide API key)
  - [ ] Hardcover (authenticated via user-specific API key)
  - [ ] Overdrive (flagged by library selection)
- local file management of books
- cover management
- obtaining covers from
  - [ ] OpenLibrary
  - [ ] Google Books
  - [ ] Hardcover
