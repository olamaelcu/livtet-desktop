Livtet downloads

Signed package repositories for the Livtet desktop app. Both channels are rebuilt from every release and signed by the same key.

Debian / Ubuntu (APT)

Add the repository key, point apt at the repository, then install: 

curl -fsSL https://download.livtet.olamaelcu.net/apt/livtet.asc \
  | sudo tee /usr/share/keyrings/livtet.asc >/dev/null
echo "deb [signed-by=/usr/share/keyrings/livtet.asc] https://download.livtet.olamaelcu.net/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/livtet.list
sudo apt update
sudo apt install livtet-desktop

Builds are published for amd64 and arm64. The key lives at apt/livtet.asc; the repository index is apt/dists/stable/InRelease.

Flatpak

Livtet needs a runtime from Flathub, so add that remote first, then the Livtet remote: 

flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak remote-add --if-not-exists --from livtet https://download.livtet.olamaelcu.net/flatpak/livtet.flatpakrepo
flatpak install livtet net.olamaelcu.livtet

The remote description, including its signing key, is at flatpak/livtet.flatpakrepo.

Direct downloads

Every release also ships the bundles themselves — .deb, .rpm, AppImage, .dmg for macOS and a .flatpak bundle — alongside a SHA256SUMS.txt:

github.com/olamaelcu/livtet-desktop/releases

Signing key fingerprint: 0728 B24D 4DF8 D0FC 1DD6 6D5A CB7F EC41 04A9 941D
